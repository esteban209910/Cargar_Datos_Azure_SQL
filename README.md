# Cargar_Datos_Azure_SQL

#  ETL hacia Azure SQL para Power BI (Modelo Estrella)


---

##  Descripción del proyecto
Este proyecto consiste en el diseño e implementación de un proceso ETL para integrar múltiples tablas desde SQL Server, aplicar transformaciones y cargar los datos en Azure SQL bajo un modelo dimensional (estrella), optimizado para análisis en Power BI.

El objetivo es centralizar la información y mejorar el rendimiento de las consultas analíticas.

---

##  Objetivo
Construir un pipeline de datos que permita transformar datos operacionales en información estructurada para análisis eficiente en Power BI.

---

##  Tecnologías utilizadas
- SQL Server  
- SQL Server Integration Services (SSIS)  
- Azure SQL Database  
- T-SQL  
- Power BI  

---

## Arquitectura del proceso

### 1. Origen de datos
- Múltiples tablas en SQL Server (modelo transaccional)  
- Datos normalizados  

---

###  2. Proceso ETL (SSIS)
- Extracción de datos desde SQL Server  
- Limpieza y transformación de datos  
- Integración de múltiples fuentes  
- Estandarización de estructuras  

---

###  3. Modelo de datos (Azure SQL)
- Implementación de modelo estrella ⭐  
- Creación de:
  - Tablas de hechos  
  - Tablas de dimensiones  
- Optimización para consultas analíticas  

---

###  4. Visualización (Power BI)
- Conexión directa a Azure SQL  
- Creación de dashboards interactivos  
- Análisis de métricas clave  

---

##  Flujo del sistema
1. Extracción de datos desde SQL Server  
2. Transformación y limpieza con SSIS  
3. Carga hacia Azure SQL  
4. Modelado en esquema estrella  
5. Consumo de datos en Power BI  

---

##  Resultados
- Integración de múltiples fuentes en un modelo analítico  
- Mejora en el rendimiento de consultas  
- Datos estructurados para análisis en Power BI  
- Base sólida para toma de decisiones
